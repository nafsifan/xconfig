# xconfig

自用分流与代理配置，覆盖 Mihomo (Clash) 与 Loon (iOS / macOS)。

## 配置模板

- `templates/clash.yaml`：Windows / 桌面端 (Mihomo)
- `templates/loon-ios.conf`：IOS
- `templates/loon-macos.conf`：MacOS

## 自建规则 (`rules/`)

### `Finance/`
- `Moomoo.list`：富途牛牛 / Moomoo
- `IBKR.list`：盈透证券
- `Wise.list`：Wise 跨境转账
- `BOCHK.list`：中银香港
- `HSBCHK.list`：汇丰香港
- `ZABHK.list`：众安银行 (ZA Bank)
- `Airstar.list`：象象银行 (Airstar Bank)

### `Gaming/`
- `SuperCell.list`：SuperCell
